# 💻 Source Code

This folder contains the complete source code of the **IPNLP Project**.

## 📦 Source Code Package

The complete project source code is provided as a ZIP archive:

**`IPNLP-Project-Source-Code.zip`**

The ZIP file contains the complete project files, including:

- 🧠 NLP/ML implementation
- 🖼️ Image processing modules
- 📊 Data processing files
- 🤖 Models and AI components
- ⚙️ Project configuration files
- 📦 Required dependencies
- 🗂️ Supporting source files

---

# ▶️ How to Run the Project

Follow the steps below to run the project on your computer.

## Step 1: Download the Source Code

Download the file:

**`IPNLP-Project-Source-Code.zip`**

from this folder.

---

## Step 2: Extract the ZIP File

After downloading the ZIP file:

1. Right-click on the ZIP file.
2. Select **Extract All**.
3. Choose a location on your computer.
4. Click **Extract**.

This will create a folder containing the complete project source code.

---

## Step 3: Open the Project Folder

1. Open the extracted project folder.
2. Check the project files and folders.
3. Open the project folder using **Visual Studio Code** or another suitable code editor.

---

## Step 4: Install Required Dependencies

Before running the project, make sure Python and the required libraries are installed.

Open the terminal inside the project folder and run:

```bash
pip install -r requirements.txt
