# 💻 Source Code

This folder contains the complete source code of the **IPNLP Project**.

## 📦 Source Code Package

The complete project source code is provided as a ZIP archive:

**`IPNLP-Project-Source-Code.zip`**

The ZIP file contains all required source files, NLP/ML implementation,
data processing, models, dependencies, and supporting files.

## ▶️ How to Run

1. Download the ZIP file.
2. Extract the ZIP file.
3. Open the extracted project folder.
4. Install the required dependencies.
5. Follow the instructions in the main
   [README.md](../README.md).
6. Run the project using the appropriate entry file.

## ⚠️ Security Note

Do not upload passwords, API keys, `.env` files, or other confidential
information to the repository.
